# .agents

Сторонние скиллы для AI-ассистента (Claude Code и другие), к коду проекта не относятся.
В `.claude/skills/` на них лежат симлинки. Собственные скиллы проекта (`prd`, `plan-phase`, `issues`) лежат прямо в `.claude/skills/`.

Содержимое помечено в `.gitattributes` как vendored: GitHub не учитывает его в статистике языков.
