# Политика безопасности

## Сообщить об уязвимости

Не создавайте публичный issue. Используйте
[приватное сообщение об уязвимости GitHub](https://github.com/aidar-khabibullin/MSA_Rocket_Factory/security/advisories/new)
(вкладка Security → Report a vulnerability) и опишите, как воспроизвести проблему.
Ответ обычно приходит в течение нескольких дней.

## Поддерживаемые версии

Исправления выпускаются только для ветки `main`.

## Важно для развёртывания

Проект учебный. Значения в `deploy/env/*.template` (пароли баз, Grafana, JWT-секреты) предназначены только для
локальной разработки. Перед любым развёртыванием вне локальной машины замените их, включите TLS на входе
(см. раздел «TLS» в [docs/architecture.md](docs/architecture.md)) и не публикуйте порты баз данных.
