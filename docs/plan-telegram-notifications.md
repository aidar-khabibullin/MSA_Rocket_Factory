# Plan: Уведомления в Telegram (notification)

**PRD:** [prd-telegram-notifications.md](prd-telegram-notifications.md)
**Дата:** 2026-11-08

## Фазы реализации

### Фаза 1: Уведомление об оплате (Tracer Bullet) — выполнена

**Цель:** Пользователь узнаёт об оплате.
**Затрагивает:** backend
**Задачи:**

- [x] Consumer `order.paid` и декодер
- [x] Клиент `iam` для получения Telegram `chat_id`
- [x] Telegram-клиент и сообщение «Заказ оплачен»
- [x] Unit-тесты

**Когда готова:** сообщение содержит ID заказа, способ оплаты и транзакцию.

### Фаза 2: Уведомление о сборке — выполнена

**Цель:** Пользователь узнаёт о готовности ракеты.
**Затрагивает:** backend
**Задачи:**

- [x] Consumer `ship.assembled` и декодер
- [x] Сообщение «Корабль собран» со временем сборки
- [x] Обработка отсутствия Telegram-метода
- [x] Unit-тесты

**Когда готова:** при отсутствии метода возвращается `telegram notification method not found`.

### Фаза 3: Защита от повторных уведомлений

**Цель:** Не слать одно уведомление дважды.
**Затрагивает:** backend
**Задачи:**

- [x] Тест: повторный `event_uuid` не вызывает обработчик (проверяется общим middleware дедупликации в `platform`, отдельного теста сервиса `notification` нет)
- [x] Ограничение повторных уведомлений по `event_uuid`

**Когда готова:** второе событие с тем же `event_uuid` не вызывает Telegram.
