# Rocket Factory: фронтенд

React 19 + TypeScript (strict) + Vite + HeroUI v3 (Tailwind v4).

## Запуск

```
task web            # BFF и фронтенд вместе (нужен поднятый бэкенд: task up-all)
task frontend:check # типы, линтер, тесты
```

Dev-сервер проксирует `/api/auth`, `/api/parts`, `/api/health` на BFF (`:8095`) и `/api/v1` на `order` (`:8080`).

## Структура

```
src/
  app/        роутер (React Router, ленивые страницы), раскладка, граница ошибок
  features/   auth, catalog, orders, system: страницы, хуки и логика по доменам
  shared/     api (HTTP-клиент, эндпоинты, типы, ключи SWR), lib (хранилище, тема, форматирование), ui
```

## Решения

- **Серверные данные: SWR.** Запросы дедуплицируются и кэшируются (каталог грузится один раз на всё приложение),
  статус оплаченного заказа опрашивается до `ASSEMBLED`, затем опрос прекращается.
- **Клиентское состояние: Zustand.** Сессия, тема и история заказов сохраняются через `persist`
  в версионированные ключи `rf:<имя>:v1`; корзина живёт только в памяти и очищается при выходе.
  Данные из `localStorage` валидируются, а сбои хранилища не ломают приложение.
- **Роутинг.** Страницы подгружаются лениво и предзагружаются по наведению на ссылку навигации;
  гость перенаправляется на `/login` в `loader`, истёкшая сессия (401) приводит к выходу.
- **Доступность.** Семантические теги (`output`, `fieldset`), статус передаётся не только цветом,
  видимый фокус, поддержка `prefers-reduced-motion`.
- **Темы.** Тёмная (Monokai Pro) и светлая (Monokai Pro Light) на токенах; выбор запоминается,
  тема применяется до первой отрисовки без мигания.
