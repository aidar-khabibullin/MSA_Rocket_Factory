# Rocket Factory: фронтенд

React 19 + TypeScript (strict) + Vite + HeroUI v3 (Tailwind v4).

## Запуск

```
task web            # BFF и фронтенд вместе (нужен поднятый бэкенд: task up-all)
task frontend:check # типы, линтер, тесты
```

Dev-сервер проксирует `/api/auth`, `/api/parts`, `/api/health` на BFF (`:8095`) и `/api/v1` на `order` (`:8080`).

## Структура (FEOD)

Слои и допустимые зависимости (проверяются `npm run lint`):

```
src/
  app/      роутер (ленивые страницы), раскладка, граница ошибок, провайдеры     -> pages, modules, common
  pages/    страницы-композиторы: собирают модули в экран                         -> modules, common
  modules/  доменные модули: auth, catalog, orders, system                        -> modules, common
  common/   api (HTTP-клиент), lib (хранилище, тема, форматирование), components  -> common
  global/   глобальные стили и настройка тестов
```

Внутри модуля (`src/modules/<имя>/`):

```
components/   UI модуля
hooks/        хуки TanStack Query (серверное состояние)
model/        чистая доменная логика и типы (без React и сети)
repository/   запросы к API и ключи TanStack Query
services/     сценарии из нескольких шагов
store/        клиентское состояние (Zustand)
index.ts      публичный API модуля
```

Правила:

- Зависимости идут только вниз по слоям; модуль не импортирует `app`/`pages`.
- Из другого слоя модуль импортируется только через публичный API: `@/modules/catalog`, а не `@/modules/catalog/hooks/...`.
  Внутри модуля используются относительные импорты.
- Модули не должны образовывать циклов: если экрану нужны два модуля (каталог и заказы), его место в `pages/`.
- Имена файлов и папок — kebab-case (`unicorn/filename-case`).

## Решения

- **Серверные данные: TanStack Query.** Запросы дедуплицируются и кэшируются (каталог грузится один раз на всё приложение),
  статус оплаченного заказа опрашивается до `ASSEMBLED`, затем опрос прекращается.
- **Клиентское состояние: Zustand.** Сессия, тема и история заказов сохраняются через `persist`
  в версионированные ключи `rf:<имя>:v1`; корзина живёт только в памяти и очищается при выходе.
  Данные из `localStorage` валидируются, а сбои хранилища не ломают приложение.
- **Роутинг.** Страницы подгружаются лениво и предзагружаются по наведению на ссылку навигации;
  гость перенаправляется на `/login` в `loader`, истёкшая сессия (401) приводит к выходу.
- **Локализация.** `i18next` + `react-i18next`, языки ru/en, словари вшиты в бандл и лежат у модулей; ключи типизированы,
  выбор языка запоминается, числа и время форматируются по языку. Подробности и правила: `AGENTS.md`.
- **DTO и адаптеры.** Формат бэкенда (snake_case) не выходит за `repository/` модуля: наружу отдаётся camelCase-модель.
- **Уведомления.** `toastService` поверх HeroUI Toast; ошибки форм остаются inline.
- **Доступность.** Семантические теги (`output`, `fieldset`), статус передаётся не только цветом,
  видимый фокус, поддержка `prefers-reduced-motion`.
- **Темы.** Тёмная (Monokai Pro) и светлая (Monokai Pro Light) на токенах; выбор запоминается,
  тема применяется до первой отрисовки без мигания.
